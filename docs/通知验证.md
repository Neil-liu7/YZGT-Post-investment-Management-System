## HTTP 与隐私检查

`tests/notifications/http.test.ts` 验证统一 `data/error/request_id` 包装、202 与最终完成的区分、相同幂等键复用结果、不同正文的幂等冲突、快照过期 409、明确接受旧稿、收件地址去重及头部注入拒绝。显式开发扫描强制使用 mock，不能由请求体改成 live。设置不返回模型密钥、SMTP 密码或飞书 Webhook。

自动批次按项目拆分、按大小分批，覆盖合成超长内容且所有成员只出现一次。飞书仅实现群机器人关键字模式，不实现签名密钥、登录、审批和回调。真实 SMTP 接收结果、飞书机器人限制及真实 GLM 模型响应仍需在用户明确授权后分别联调，不从模拟测试推断已经真实送达。
